| Saved with the show | Saved on this machine |
|---|---|
| Timeline settings (new clip length, show length) | Interface colours, language, window |
| Timecode source, fps, start time | Performance (cook rate, VSync, preload) |
| Output groups and outputs | Autosave, projects folder |
