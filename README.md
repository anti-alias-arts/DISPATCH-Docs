# DISPATCH Docs

User documentation for DISPATCH, built with MkDocs Material. Same setup and theme as AAVJ-Docs.

- Pages are in `docs/`, screenshots in `docs/Images/`.
- Pushing to `main` builds and publishes the site to GitHub Pages (`.github/workflows/ci.yml`).
- Preview locally: `pip install "mkdocs<2" "mkdocs-material<10"`, then `mkdocs serve`.
